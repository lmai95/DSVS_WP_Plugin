# DSVS WP Plugin
Version 0.3.2. Multi-Liga DSVS WordPress integration. Styling uses Elementor Global Colors `Primary`, `Secondary`, `Text` and `Accent` with fallbacks for non-Elementor themes. Shortcodes: `[dsv_tabelle liga="C2"]`, `[dsv_aktuelle_spiele liga="C2"]`, `[dsv_kommende_spiele liga="C2" anzahl="4"]`.
